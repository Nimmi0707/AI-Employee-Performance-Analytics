
# AI Employee Performance Analytics

## Project Overview
This project uses Machine Learning to analyze and predict employee performance based on experience, training hours, attendance, and completed projects.

## Objectives
- Analyze employee performance data
- Apply Machine Learning algorithms
- Predict employee performance scores
- Evaluate model performance using MAE, RMSE, and R2 Score

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab
- Machine Learning

## Machine Learning Models
- Linear Regression
- Model Evaluation
- Cross-Validation

## Results
The Linear Regression model achieved an R2 Score of 0.85 on the test dataset and an average cross-validation R2 Score of 0.73.

## Disclaimer
This project is developed for academic and educational purposes using synthetic data. It should not be used for real employee evaluation without proper validation and fairness assessment.
